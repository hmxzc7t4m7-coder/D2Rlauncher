# Third-Party Notices

D2RLauncher uses third-party software and expects runtime components to be distributed as separate release artifacts.

## Wine (LGPL)
- Wine is licensed under the GNU Lesser General Public License (LGPL).
- When redistributing Wine binaries, corresponding source code and license notices must be provided according to LGPL terms.
- Runtime bundles published for D2RLauncher should include license text and source-offer/compliance materials.

## DXVK
- DXVK licensing varies by release metadata and included notice files.
- Runtime bundles must include the exact upstream license text shipped with the included DXVK version.

## VKD3D
- VKD3D and related components may be distributed under LGPL or project-specific terms.
- Runtime bundles must include the exact upstream license text for the shipped build.

## Blizzard Software
- D2RLauncher does not redistribute Diablo II: Resurrected binaries.
- Battle.net installer inclusion should be done only where redistribution terms permit it.
- Safer default is user-provided installer or official direct download initiated in-app.
